# Strange but True

**Tech, art and ideas that'll actually help.**

Strange but True is the public business, creative and community-project doorway of Luke Nathan Hayes, based in Amity on Minjerribah (North Stradbroke Island), Queensland, Australia.

The website connects practical local services with independent research, music, filmmaking, public speaking, leadership advisory and a wider portfolio of community and whole-system development work. Visitors can start with a small practical problem, explore the creative catalogue, or follow a project from the island to the wider world.

## A Fair Go in the Age of Superintelligence

The [speaking programme](https://auraofintelligence.github.io/strange-but-true/public-speaking.html) brings together more than a decade of independent research and development, with a particular emphasis on the opportunities and decisions facing Queensland before Brisbane 2032.

Its eight connected themes run from the personal to the planetary:

1. **Aura of Intelligence:** a developing personal digital-twin environment connecting memories, skills, values, relationships and ambitions.
2. **The missing middle of compute:** community computing infrastructure, useful heat, backup power, ownership, training and renewal.
3. **Sovereign AI:** personal and cultural data authority, hardware, models, consent, portability and locally governed infrastructure.
4. **Mutual Futures:** productive ownership, business succession, paid mentoring, learning, care and time through the AI and automation transition.
5. **C-Hours:** recognition of verified voluntary human contribution, separate from wages and financial value.
6. **P4A, the Purple Party for Australia:** democratic participation, legal memory, public evidence, accountability and a fair go in the age of powerful intelligence. The Australian Household Bill Check gives this work an everyday starting point.
7. **Long-term civilisation planning:** resilient energy, food, water, shelter, repair, retained knowledge and terrestrial and celestial risks.
8. **GAJRA Earth:** re-imagining multilateral cooperation through locally shaped associations, sovereign choices and shared planetary capability.

Engagement formats include 45-60 minute keynotes plus discussion, 60-90 minute seminars/roundtables, and half-day, full-day or multi-session workshops. The programme distinguishes working prototypes, evidence, proposals and speculative futures, inviting questions and disagreement rather than presenting one predetermined future.

See the [independent UNGA81 contribution](https://auraofintelligence.github.io/UNGA81-Luke-Hayes/), [Australian Household Bill Check](https://auraofintelligence.github.io/household-bill-check/) and [Luke Nathan Hayes: An Open Record](https://github.com/auraofintelligence/open-record-luke-nathan-hayes).

### Paid community contributions and voluntary C-Hours

Two distinct proposed pathways are described:

- **Paid community contributions:** iCi/SOL/XRP is a proposed avenue for recording paid project work and recognising it through a local leaderboard. Public profiles, wallet records, verification and implementation details remain to be developed.
- **C-Hours:** one verified C-Hour recognises one freely given human hour. It is non-financial, with no monetary conversion. Paid work and its leaderboard do not form part of C-Hours.

Neither pathway is a requirement for ordinary business enquiries, service payments or music purchases. The website does not establish an operational token exchange, blockchain ledger, public-profile system or automatic community-contribution verification. See [C-Hour Introduction](https://auraofintelligence.github.io/C-Hour-introduction/) for the separate voluntary contribution proposal.

### Checkout implementation and activation status

**The checkout code exists, but payments are not open.** The current public configuration in [checkout-config.js](checkout-config.js) has an empty Apps Script endpoint.

The dedicated checkout implementation in [tools/checkout/](tools/checkout/) supports Stripe-hosted Checkout and PayPal Orders v2:

- Server-side validation of album IDs and independent calculation of the AUD package price.
- Hosted provider payment pages; the site does not collect card numbers.
- Payment verification against the stored order, amount, currency and completed payment status, including PayPal capture and subsequent retrieval.
- Stable request IDs, retry handling, idempotency, input validation and protected return-access tokens.
- Private Google Sheets order records and owner notification after verified payment.
- Optional scheduled reconciliation, once configured, to recover completed payments where a buyer does not return to the site.
- Manual digital fulfilment by Luke after payment verification; no automatic download entitlement or file unlock.

Deploy the checkout as its own Apps Script web app, separate from the contact/feedback script. Keep payment credentials, owner notification details and signing secrets in private Script Properties, not public JavaScript. Test both providers, all four package prices, cancellation, retries, reconciliation and actual delivery before enabling live payments.

Full deployment, security considerations and test instructions: [Digital album checkout](tools/checkout/README.md).

### Local preview and testing

```sh
git clone https://github.com/auraofintelligence/strange-but-true.git
cd strange-but-true
python -m http.server 8000
```

Open http://localhost:8000/ in a browser. Network services, external embeds and forms depend on their actual external deployments. Opening the local site does not create a private order database or enable payments.

Run the checkout's mocked, non-network validation with Node.js:

```sh
node tools/checkout/test-checkout.cjs
```

The tests do not verify provider accounts, real Apps Script deployments, sender access, fulfilment, refunds or real payments. Consult the checkout documentation for account-level acceptance checks.
